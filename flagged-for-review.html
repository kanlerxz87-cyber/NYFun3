How to use this page

  • Blank is a value. A blank cell with unverified means the official source did not publish the fact; it never means zero.
  • Do not infer 2027. Stars, schedules, hotel rates, and menu prices may change before travel.
  • Source links are starting points. Use them to re-check the fact on the operator, venue, Guide, or transit authority’s own page.
  • Latest audit: read the 26 November 2026 decision-readiness audit for the full coverage table and unresolved evidence gaps.
  • Evidence quality: read EVIDENCE_AUDIT.md for how far each table can be trusted, and FLAGS.md for the list of defects: dead hotel domains, the Blue Angel address conflict, the Pestana fee arithmetic, the 67-versus-72 star-count mismatch, and the 261 search links that were labelled as reviews.
  • Coordination: the task board and work logs are in COORDINATION.md; the curated dossier’s own findings are in pages/findings.html.
