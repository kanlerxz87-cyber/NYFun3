How to clear a flag

  1. Open the “Official source” link; find the value; match it against the page that flagged it.
  2. If confirmed → change badge from Unverified to Verified ✓ with date; remove from this list; commit.
  3. If contradicted → correct the value, cite the new official source, note the correction in the Sources page changelog, and commit.
  4. If still unverifiable → leave blank; keep the flag; say so in the PR description.
