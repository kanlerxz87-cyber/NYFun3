# NYFun3 — NYC Trip Planner (Feb 15–18, 2027 preferred)

Verified planning site for a 2-adult New York City trip: Michelin restaurants, hotels (7-night totals), activities with official hours, itinerary, analysis, open questions, suggestions, and a flagged-for-review list.

**Live site:** https://kanlerxz87-cyber.github.io/NYFun3/ (GitHub Pages, published from this branch)

## Contents
- `index.html` — dashboard landing
- `pages/` — executive-summary · itinerary · hotels · restaurants · activities · analysis · questions · suggestions · flagged · sources
- `assets/` — style.css · app.js · favicon.svg
- `COORDINATION.md` — multi-agent task board (claims, verification log, irregularities)

## Verification policy
Nothing is marked verified without an official source checked on 2026-11-25. Unverifiable values are left blank and flagged on the Flagged for Review page. Social links are search URLs (handles unverified). Hotel Feb-2027 pricing is not publicly confirmable — snapshots are labeled estimates, never quotes.
