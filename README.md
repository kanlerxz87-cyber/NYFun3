# New York Trip Desk

A static, mobile-friendly planning dashboard for a New York trip for two. Open `index.html` locally or publish the repository root with GitHub Pages. Category pages live in `pages/`; styling is in `assets/style.css`.

Sources are linked in each table row. Research snapshot: November 25, 2026. The site explicitly flags unverified hotel quotes, private bathrooms, transit counts, future schedules and other missing evidence; it is not an exhaustive inventory or a booking confirmation.
